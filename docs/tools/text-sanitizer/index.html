Sanitizador de Texto

Pegá texto sucio, aplicá reglas de limpieza y obtené un resultado seguro con un registro de lo detectado.

Limpiadores

Registro de detección

    ¿Cómo funciona?

    El sanitizador procesa el texto completamente en tu navegador. Primero aplica los limpiadores que elijas en un orden fijo, y luego el modo de escape seleccionado. Cada transformación que produzca cambios se registra con la cantidad de caracteres afectados y un ejemplo representativo.

    Limpiadores

    Eliminá caracteres de control ASCII, bytes nulos, caracteres Unicode de ancho cero, normalizá saltos de línea a LF, recortá espacios laterales y colapsá espacios consecutivos.

    Modos de escape

    Escapá comillas y barras, prepará una cadena JSON, convertí a entidades HTML o codificá para URLs de forma inmediata y predecible.

    Ejemplos de uso

    • Limpieza básica: hola\x02mundo con "Remover caracteres de control" devuelve holamundo.
    • Saltos de línea: mezclas de \r\n, \r y \n se normalizan a un único \n.
    • Escape JSON: linea"uno\nlinea"dos se convierte en linea\"uno\\nlinea\"dos.

    Privacidad: todo el procesamiento ocurre en tu navegador. El texto nunca se envía a ningún servidor.

Conversor de Colores

Transforma colores entre múltiples formatos al instante y copia el resultado.

Vista previa

¿Qué formatos soporta?

El conversor trabaja internamente con el modelo sRGBA de 8 bits y permite cambiar entre HEX, RGB/RGBA, HSL/HSLA, HSV/HSVA y CMYK/CMYKA. Todos los valores se normalizan y recortan a rangos válidos automáticamente.

Modelo RGB

RGB define colores combinando luz roja, verde y azul. Es el formato nativo de pantallas y navegadores, ideal para CSS y diseño web.

HSL y HSV

HSL (Tono, Saturación, Luminosidad) y HSV (Tono, Saturación, Valor) describen colores de forma más intuitiva para humanos, facilitando ajustes de matiz y brillo.

Casos de uso comunes

  • Diseño web: pasa de un selector visual a códigos HEX o RGB listos para CSS.
  • Impresión: convierte colores digitales a CMYK para preparar archivos de imprenta.
  • Accesibilidad: ajusta la transparencia alpha manteniendo el color base intacto.

Nota: la conversión entre espacios de color discretos puede producir pequeñas diferencias de redondeo. Los valores se muestran con un decimal para porcentajes y grados, y enteros para canales RGB.

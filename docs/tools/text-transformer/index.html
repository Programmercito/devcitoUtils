Transformador de Texto

Convierte una entrada en múltiples formatos de caso en tiempo real.

¿Cómo funciona?

Escribe o pega cualquier texto y la herramienta lo tokeniza automáticamente usando espacios, signos de puntuación, guiones, barras y cambios de mayúsculas. Cada formato de salida se genera a partir de esos tokens de forma pura y predecible.

Casos para código

Obtén camelCase para variables, PascalCase para clases, snake_case para Python, kebab-case para CSS y CONSTANT_CASE para configuraciones sin esfuerzo.

Casos para contenido

Convierte títulos a Title Case, frases a Sentence case o genera variantes con puntos, barras y guiones para slugs y rutas.

Ejemplos de uso

  • APIs y variables: hello world → helloWorld o hello_world.
  • Slugs y URLs: Hello World → hello-world o hello/world.
  • Clases y constantes: hello world → HelloWorld o HELLO_WORLD.

Privacidad: todo el procesamiento ocurre en tu navegador. El texto nunca se envía a ningún servidor.

¿Qué es un UUID?

Un UUID (Universally Unique Identifier) es un identificador de 128 bits diseñado para ser único en el espacio y en el tiempo. Se usa en bases de datos, APIs, nombres de archivos, sesiones y cualquier lugar donde necesites un ID que no colisione.

v4 — Aleatorio

Generado con aleatoriedad criptográfica. Es el más común cuando no necesitás orden.

v7 — Sortable

Combina un timestamp de 48 bits con aleatoriedad. Ideal para claves primarias ordenables.

Múltiples formatos

Estándar, sin guiones, Base64, Base62, URN, C# Guid, entre llaves o paréntesis.

Ventajas

  • Privado: todo se genera localmente en tu navegador.
  • Versátil: soporta v1, v4, v7, nil y max.
  • Validador integrado: verificá si un string es un UUID válido y detectá su versión.
  • Bulk: generá hasta 1000 UUIDs de una vez.

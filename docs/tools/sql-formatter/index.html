Formateador y Minificador de SQL

Pegá tu consulta SQL, elegí el dialecto y las opciones de formato, y obtené el resultado listo para copiar.

¿Por qué usar un formateador SQL?

Las consultas SQL bien formateadas son más fáciles de leer, depurar y compartir con tu equipo. Ya sea que recibas SQL minificado en una sola línea o necesites estandarizar el estilo de tu código, nuestro formateador te permite aplicar reglas claras de indentación y mayúsculas/minúsculas en segundos.

Múltiples dialectos

Soportamos PostgreSQL, MySQL, SQLite, SQL Server, BigQuery, Snowflake, DuckDB y muchos más, para que el formato respete la sintaxis de tu base de datos.

Privacidad garantizada

El formateador se carga directamente en tu navegador. Tus consultas nunca se envían a ningún servidor ni quedan almacenadas.

Minificación incluida

Además de formatear, podés reducir una consulta a una sola línea para incluirla en payloads, logs o configuraciones.

Ventajas de nuestra herramienta

  • 100% privado: todo el procesamiento ocurre en el cliente gracias a sql-formatter v15 cargado desde jsDelivr.
  • Opciones flexibles: elegí el dialecto, el ancho de indentación (de 1 a 8 espacios) y el caso de las palabras clave.
  • Ejemplo incluido: cargá una consulta de ejemplo para probar el formateador sin escribir nada.
  • Manejo de errores: mensajes claros en español cuando el SQL no se puede parsear.
  • Copiado rápido: copiá el resultado al portapapeles con un solo clic.

Tip Pro: si trabajás con varias bases de datos, seleccioná siempre el dialecto correcto. Algunas sintaxis específicas, como los identificadores entre corchetes de T-SQL o los strings con dólar de PostgreSQL, solo se interpretan bien con el dialecto adecuado.

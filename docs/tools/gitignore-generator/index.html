¿Por qué usar un generador de .gitignore?

Un buen .gitignore evita que archivos innecesarios, sensibles o generados por tu entorno terminen en el repositorio. Cada lenguaje, framework y editor tiene sus propios archivos para ignorar, y armar el archivo a mano es repetitivo y propenso a errores.

Sin duplicados

Las plantillas se concatenan con secciones claras para que el archivo sea fácil de mantener.

Descarga directa

Generá, copiá o descargá el archivo .gitignore con un clic.

Cómo funciona

  1. Buscá y seleccioná las plantillas que correspondan a tu proyecto.
  2. Elegí si querés encabezados de sección y orden alfabético.
  3. Copiá el contenido o descargá el archivo .gitignore.
